# Output File Naming Conventions

This document details the naming conventions for Parquet output files generated by `neuroalign-preprocessing`. These conventions ensure that output filenames are BIDS-like and comprehensively describe their aggregated content and processing parameters.

## General Structure

All output Parquet files will follow a structured naming convention:

`<entities>_parc.parquet`

Where `<entities>` is a series of key-value pairs separated by underscores, and `parc.parquet` indicates a parcellated Parquet file.

## Entity Descriptions

The following entities may be included in the filename, depending on the data source and processing parameters:

*   **`atlas-<label>`**: (Required) Specifies the name of the atlas used for parcellation (e.g., `Schaefer2018N400n7Tian2020S3`).
*   **`space-<label>`**: (Fixed) Indicates the anatomical space of the data. Currently fixed to `MNI152NLin2009cAsym`.
*   **`res-<value>`**: (Fixed) Indicates the spatial resolution. Currently fixed to `01`.
*   **`mask-<label>`**: (Optional) Specifies the mask used (e.g., `gm` for gray matter). This corresponds to the `--mask` CLI argument.
*   **`maskthr-<value>`**: (Optional) Specifies the threshold applied to the mask (e.g., `50`). This corresponds to the `--maskthr` CLI argument.

### Modality-Specific Entities

#### CAT12 Output Files

For CAT12 aggregated data, the following entity is included:

*   **`tissue-<label>`**: (Required) The tissue type being aggregated (e.g., `GM`, `WM`, `CT`).

**Example CAT12 Filename:**
`atlas-Schaefer2018N400n7Tian2020S3_space-MNI152NLin2009cAsym_res-01_tissue-GM_mask-gm_maskthr-50_parc.parquet`

#### QSIParc Output Files

For QSIParc aggregated data, the following entities are included:

*   **`model-<label>`**: (Required) The diffusion model used (e.g., `tensor`, `csd`).
*   **`param-<label>`**: (Required) The parameter derived from the diffusion model (e.g., `md`, `fa`).

**Example QSIParc Filename:**
`atlas-Schaefer2018N400n7Tian2020S3_space-MNI152NLin2009cAsym_res-01_model-tensor_param-md_mask-gm_maskthr-50_parc.parquet`

## CLI Arguments Affecting Naming

The `--atlas`, `--mask`, and `--maskthr` CLI arguments directly influence the generated filenames. Ensuring these are set appropriately will result in descriptive and standardized output file names.
